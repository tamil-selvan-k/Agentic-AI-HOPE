# Catch-up checkpoints

Copy a folder's files over the student's files with the same path. Each includes the earlier parts.
None contains a lab answer.

| Folder | Hand out when | Leaves as TODO |
|---|---|---|
| `after-part1/` | Part 1 ends and the queue tests aren't green | Parts 2, 3, all labs |
| `after-part2/` | Part 2 ends and the idempotency tests aren't green | Part 3, all labs |
| `after-part3/` | Part 3 ends, or a student is stuck during the sprint | all labs |

`after-part2/` and `after-part3/` contain every file changed so far, so one copy is enough.
